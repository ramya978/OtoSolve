Why this record exists

A user account lets one person sign in, with one primary role, a data scope and an access window. Every action they take is tied to it in the audit trail.

Protected core

The user reference stays permanent. The login e-mail and username lock once the invitation is accepted. Role, scope and window can change later with a recorded reason.
